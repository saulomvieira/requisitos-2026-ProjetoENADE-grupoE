# Documento de Visão

# 1. Introdução

## 1.1 Objetivo do Documento
Este documento tem como objetivo apresentar a visão geral do sistema de apoio ao ENADE, descrevendo o problema identificado, os objetivos do projeto, o público-alvo e as principais funcionalidades previstas.

---

# 2. Descrição do Problema

O ENADE é um exame obrigatório aplicado aos estudantes do ensino superior e representa um importante indicador da qualidade acadêmica das instituições de ensino.

Entretanto, muitos estudantes enfrentam dificuldades durante a preparação para a prova devido à falta de materiais organizados, simulados práticos e ferramentas que auxiliem no acompanhamento do desempenho.

Além disso, existe a necessidade de um ambiente centralizado que permita acesso facilitado a questões comentadas, estatísticas e simulados semelhantes ao exame real.

---

# 3. Proposta de Solução

O projeto propõe o desenvolvimento de um sistema web/mobile voltado para a preparação de estudantes para o ENADE.

O sistema permitirá:

- Realização de simulados cronometrados;
- Acesso a banco de questões organizadas;
- Visualização de estatísticas de desempenho;
- Consulta de gabaritos comentados;
- Interação entre usuários por meio de fórum.

---

# 4. Público-Alvo

O sistema será destinado principalmente para:

- Estudantes de graduação;
- Professores;
- Coordenação acadêmica;
- Administradores do sistema.

---

# 5. Objetivos do Projeto

## Objetivo Geral
Aplicar conceitos de engenharia de requisitos para especificar um sistema de apoio aos estudos para o ENADE.

---

## Objetivos Específicos

- Realizar elicitação de requisitos com estudantes;
- Modelar o sistema utilizando diagramas UML;
- Desenvolver documentação SRS baseada no padrão IEEE 830;
- Criar protótipos das principais funcionalidades do sistema.

---

# 6. Benefícios Esperados

Com o desenvolvimento do sistema, espera-se:

- Melhorar a preparação dos estudantes para o ENADE;
- Facilitar o acesso a materiais de estudo;
- Auxiliar instituições no acompanhamento de desempenho;
- Promover aprendizado colaborativo entre usuários.
