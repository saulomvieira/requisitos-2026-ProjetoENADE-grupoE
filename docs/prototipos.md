# Protótipos

## Tela 1 – Login

A tela de login deverá conter:

- Campo para inserção de e-mail;
- Campo para inserção de senha;
- Botão **“Entrar”**;
- Link **“Criar conta”** para novos usuários.

---

## Tela 2 – Cadastro

A tela de cadastro deverá conter:

- Campo para nome completo;
- Campo para e-mail;
- Campo para senha;
- Botão **“Cadastrar”**.

---

## Tela 3 – Dashboard

A dashboard principal deverá apresentar:

- Botão **“Iniciar Simulado”**;
- Acesso ao banco de questões;
- Estatísticas resumidas de desempenho do usuário.

---

## Tela 4 – Simulado

A tela de simulado deverá conter:

- Questões com alternativas;
- Temporizador para controle do tempo;
- Botão **“Finalizar”**.

---

## Tela 5 – Resultado

A tela de resultado deverá apresentar:

- Quantidade de acertos e erros;
- Tempo gasto no simulado;
- Acesso ao gabarito comentado.
