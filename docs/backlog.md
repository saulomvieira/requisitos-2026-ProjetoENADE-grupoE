# Backlog Priorizado

| ID | User Story | Prioridade | Critério de Aceite |
|---|---|---|---|
| US01 | Como estudante, quero me cadastrar no sistema para acessar as funcionalidades. | Alta | O usuário consegue criar conta com e-mail e senha válidos. |
| US02 | Como usuário, quero fazer login para acessar o sistema. | Alta | O sistema valida o login corretamente. |
| US03 | Como estudante, quero acessar questões do ENADE para estudar. | Alta | As questões são exibidas por área e ano. |
| US04 | Como estudante, quero realizar simulados para testar meu conhecimento. | Alta | O simulado inicia com tempo definido. |
| US05 | Como estudante, quero visualizar meu desempenho para acompanhar minha evolução. | Alta | O sistema apresenta número de acertos, erros e tempo gasto. |
| US06 | Como estudante, quero visualizar o gabarito comentado para entender meus erros. | Média | O sistema exibe a explicação da resposta correta. |
| US07 | Como estudante, quero participar de um fórum para tirar dúvidas. | Baixa | O usuário consegue comentar nas questões. |
| US08 | Como professor, quero cadastrar questões para alimentar o sistema. | Média | A questão é salva corretamente no banco de dados. |
| US09 | Como administrador, quero gerenciar usuários para manter o controle do sistema. | Média | O administrador consegue ativar e desativar usuários. |
| US10 | Como coordenação, quero gerar relatórios para acompanhar o desempenho geral. | Média | O relatório é exibido por curso e área. |
