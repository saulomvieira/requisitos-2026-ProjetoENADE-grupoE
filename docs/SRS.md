# Especificação de Requisitos de Software (SRS)

# 1. Introdução

## 1.1 Propósito
Este documento tem como objetivo especificar os requisitos do sistema de estudos para o ENADE, descrevendo suas funcionalidades, restrições e características principais.

---

## 1.2 Escopo
O sistema permitirá que estudantes realizem simulados, acessem questões comentadas e acompanhem seu desempenho, auxiliando na preparação para o ENADE.

---

## 1.3 Definições

- **ENADE:** Exame Nacional de Desempenho dos Estudantes;
- **Usuário:** Estudante, professor ou administrador;
- **Simulado:** Prova realizada com tempo controlado.

---

# 2. Descrição Geral

## 2.1 Perspectiva do Produto
O sistema será uma aplicação web/mobile independente, acessada por meio de navegador ou dispositivo móvel.

---

## 2.2 Funções do Produto

O sistema deverá oferecer as seguintes funcionalidades:

- Cadastro e login de usuários;
- Banco de questões;
- Realização de simulados;
- Estatísticas de desempenho;
- Fórum de interação entre usuários.

---

## 2.3 Usuários

O sistema será destinado aos seguintes perfis de usuários:

- Estudantes;
- Professores;
- Administradores;
- Coordenação acadêmica.

---

# 3. Interfaces Externas

## 3.1 Interface do Usuário

A interface deverá possuir:

- Design responsivo;
- Navegação simples e intuitiva.

---

## 3.2 Interface de Sistema

O sistema deverá utilizar:

- Banco de dados para armazenamento de usuários e questões.
