# Stakeholders

# 1. Introdução

Este documento apresenta os stakeholders envolvidos no projeto do sistema de apoio ao ENADE, identificando os principais usuários e interessados no desenvolvimento da solução.

---

# 2. Stakeholders Identificados

## 2.1 Estudantes

Os estudantes representam o principal público-alvo do sistema.

### Responsabilidades e interesses:
- Realizar simulados;
- Acessar questões comentadas;
- Acompanhar desempenho;
- Participar do fórum de discussão.

---

## 2.2 Professores

Os professores poderão utilizar o sistema como apoio pedagógico.

### Responsabilidades e interesses:
- Cadastrar questões;
- Auxiliar estudantes;
- Acompanhar desempenho acadêmico;
- Participar das discussões do fórum.

---

## 2.3 Coordenação Acadêmica

A coordenação acadêmica poderá acompanhar indicadores relacionados ao desempenho dos estudantes.

### Responsabilidades e interesses:
- Gerar relatórios;
- Monitorar resultados;
- Identificar dificuldades dos estudantes;
- Apoiar ações de melhoria acadêmica.

---

## 2.4 Administradores do Sistema

Os administradores serão responsáveis pelo gerenciamento da plataforma.

### Responsabilidades e interesses:
- Gerenciar usuários;
- Controlar permissões;
- Garantir funcionamento do sistema;
- Manter segurança e disponibilidade.

---

# 3. Conclusão

A identificação dos stakeholders é fundamental para garantir que os requisitos do sistema estejam alinhados às necessidades dos diferentes perfis envolvidos no projeto.
